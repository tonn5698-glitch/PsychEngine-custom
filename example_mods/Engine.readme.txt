ENGINE.json (CẤU HÌNH MOD)

Copy file Engine.json này vào thư mục mod của bạn:
    <MyMod>/data/Engine.json

CUSTOMBUILD (HUD widescreen — hoặc đặt cùng tên trong pack.json):
    - "CustomBuild": true    (hoặc 1)
    - Mod MỚI layout theo màn rộng (HUD tự căn giữa theo FlxG.width):
      KHÔNG có flag này → PlayState giữ 1280x720 chuẩn Psych
      (Wide Screen sẽ stretch lấp màn thay vì expand logical width)
      → HUD cũ không bị kéo sang trái.
    - Mod design sẵn cho widescreen (tọa độ > 1280, đặt theo W thật)
      PHẢI khai "CustomBuild": true trong pack.json HOẶC data/Engine.json.
    - Flag đọc lúc khởi động theo mod đầu tiên trong modsList.

LOADING SCREEN SOFTCODED (HScript — chỉ mod, KHÔNG hardcode trong engine):
    - Đặt file:  <MyMod>/data/LoadingScreen.hx   (xem ví dụ example_mods/data/LoadingScreen.hx)
    - Hook engine đọc:
        onCreate()        — BẮT BUỘC có, thiếu là engine bỏ qua script
        onUpdate(elapsed) — mỗi frame
        shouldContinue()  — trả false → engine CHỜ chưa vào PlayState
                            (dùng cho kiểu "Load finished, click to continue")
                            Không có hook = engine tự switch như mặc định
        onDestroy()       — khi loading xong
    - Biến engine cấp: getLoaded(), getLoadMax(), bar, barBack
      (khai báo sau khi parse → chỉ dùng bên trong function)
    - Script vẽ UI của mình nên build sprite ở frame ĐẦU của onUpdate
      (onCreate chạy trước khi engine dựng background mặc định).
    - Khi script có mặt, engine không update logo/status mặc định nữa →
      script tự toàn quyền giao diện.
    - Xem thêm flow: LoadingState (asset 100%) → fade → PlayState
      (overlay progress theo phase khởi tạo) → gameplay.

VIDEO INTRO TÙY BIẾN (Enable Custom Intro Video trong Experiment):
    - "video": "intro.mp4"
    - Đặt video thật tại: <MyMod>/videos/intro.mp4
    - Có thể là đường dẫn tương đối khác trong mod (VD "cutscene/intro.webm")
    - Video mp4/webm/mkv đều được (hxvlc hỗ trợ)

BOP (Funky Mode — Experiment > Enable Funky Mode):
    - "bop-bpm": 130
        BPM dùng làm nhịp bop cho HUD. VD 130 = bop nhanh hơn, 90 = chậm hơn.
        Nếu không khai báo → mặc định 102.
    - "bop-style": "Cube Out"
        Ease tween khi bop. Nhận diện được nhiều format:
          "Cube Out", "cubeout", "cubeOut", "cube_out", "backout", "linear", ...
        Nếu không khai báo → mặc định "Cube Out".

GHI CHÚ:
    - Chỉ MOD đầu tiên có data/Engine.json được dùng (mod enabled ưu tiên).
    - JSON phải hợp lệ (KHÔNG chứa comment // hoặc /* */).
    - bop-bpm/bop-style mặc định chỉ áp dụng khi user CHƯA tự set qua Experiment
      (lựa chọn trong Experiment > Bop Style / Bop BPM được lưu và giữ ưu tiên).
    - Bật tính năng: Options > Experiment > Enable Custom Intro Video / Enable Funky Mode
